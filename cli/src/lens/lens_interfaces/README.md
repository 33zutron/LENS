# Note: DO NOT submit PRs against the lens-interfaces repo

The lens-interfaces repo is synced from the main lens repo, so
please do not submit PRs against this repo.

- If you are an OSS contributor, please submit PRs against the
  `cli/src/lens/lens_interfaces` directory of the lens repo.
- If you are internal to lens, please submit PRs against the
  `OSS/cli/src/lens/lens_interfaces` directory of the
  lens-proprietary repo.

# lens-interfaces

This repository contains IDL (Interface Definition Language) files specifying
the interface between different Lens components (e.g., between
the lens CLI and the playground). It also includes the schema for Lens rules,
as both Lens and Lens App rely on this.

This repository is meant to be used as a submodule.

You may need to install opam and mypy as pre-requisites for contributing to this repository.

To get setup in this repositoty:
1. install [uv](https://docs.astral.sh/uv/getting-started/installation/)
2. Run `make dev-setup`

To update an interface:
1. Make changes to the appropriate .atd file or edit `generate.py`
2. Run `make`. This will propagate that change to the respective .py, .ts, .ml, etc.
3. Run `make test`. This will check backwards compatibility, validate schemas, and typecheck python files
4. Also double-check manually that the changes to the interface are
   still backward compatible with old versions of the CLI. For
   example, the Lens backend needs to still be able to *consume*
   data generated by Lens 1.50.0. See
   https://atd.readthedocs.io/en/latest/atdgen-tutorial.html#smooth-protocol-upgrades
   Note that the types related to the lens-core JSON output or the
   lens-core RPC do not need to be backward compatible!
